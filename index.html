常见问题

暮冬念春是免费的吗？
是的。暮冬念春采用 MIT 协议开源，软件本身永久免费，你也可以在 GitHub 上查看、修改与分发源码。
使用时需要联网吗？
不需要。软件完全在本地运行，拆书、蒸馏、写作、质检等核心功能均可离线使用（AI 生成能力取决于你配置的模型）。
我的小说数据会被上传吗？
不会。服务硬绑定本机地址（127.0.0.1），不对外暴露；你的书稿、资产与配置只保存在你自己的电脑上。
需要自己安装 Python 吗？
不需要。Windows 安装包内置了 Python 运行时，双击装完就能用，不用配置任何开发环境。
除了桌面版，还有别的用法吗？
有。桌面版之外还提供 CLI 引擎 novel.py（20 多个中文子命令），适合习惯命令行的用户；开发者也可以直接从源码运行。
